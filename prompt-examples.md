# Vox-style video prompts: examples

How to ask for a new motion video. Copy a template, swap in your draft, images and style.

## The template

```
please create a motion video with this detail @"<draft>.md" and these images (@<img1>.jpg, @<img2>.jpg).

style: vox-style documentation, <style name>. <new style, completely different from previous videos | variation of <existing style>>.
look: <palette>, <paper/texture>, <type>, <how to treat my photos>, <characters/props>.
motion: <how things move>, <transition between scenes>.
structure: <default | split comparison | countdown | timeline>.
audience: <who>. tone: <casual / formal / slang>. language: <Indonesian / English>.
duration: <~45 s | ~60 s | ~80 s>. vertical 9:16.
preview first: <yes / no>. AI-generated images: <no | yes, use Higgsfield>.
```

You don't need every line. **style**, **look** and **audience** matter most. Everything you leave out gets a sensible default (Indonesian if the draft is Indonesian, ~60–80 s, silent, the usual structure).

### What each line changes

| Line | Changes | Examples |
|---|---|---|
| style name | the overall genre | chalkboard, newspaper collage, comic book, neon, archive file |
| new vs variation | new engine vs new "vibe" on an old one | "completely different" / "variation of the papercraft style" |
| palette | colours | "black + one red accent", "warm pastel", "neon pink and cyan on navy" |
| texture | surface | "chalk dust", "newsprint grain", "manila folder", "risograph" |
| type | fonts | "condensed caps", "typewriter", "handwritten chalk", "comic lettering" |
| photo treatment | how your images look | engraving, halftone, cut-paper, polaroid, sticker cutout, duotone |
| characters/props | things on screen | mascot, magnifying glass, boombox, stamps, pins and red string |
| motion | animation | stop-motion, smooth glide, glitch, chalk drawn stroke by stroke |
| transition | between scenes | page turn, sheet slides up, eraser wipe, panel cut |
| structure | layout | default (hook → title → categories → key points → sources), split comparison, countdown |
| audience + tone | wording | "teen, casual slang", "professionals, formal", "kids, playful" |

```
please create a motion video with this detail @"20261012 - content.md" and these images (@01-tinggi-serat.jpg, @02-sedang-serat.jpg, @03-tanpa-serat.jpg).

```

## Example 6: a variation of an existing style (fast)

Use this when you like a style you already have and only want a new mood. It reuses an existing engine and adds a "vibe", like the hip-hop version.

```
please create a motion video with this detail @"<draft>.md" and these images (@a.jpg, @b.jpg).

style: variation of the papercraft style, K-pop vibe.
change only: palette to pink, lilac and baby blue; idol-stage set with paper spotlights and a heart-shaped light stick;
the mascot wears a sparkly jacket; chunky rounded headlines; sticker hearts and sparkles.
keep: cut-paper diorama, stop-motion, layout and timing.
audience: teens. tone: cute and hype. language: Indonesian.
```

## Small follow-up prompts (after the first render)

```
make it shorter, around 45 s
the hook is too slow, make the question appear in the first second
change the palette to <...>, keep everything else
make the text bigger on the item list
change the mascot to a broccoli
write the copy in English instead
render a preview still of the third scene only
create the caption and hashtag in md file
```

## Tips

- **Say "completely different from previous videos"** when you want a new look; otherwise I may reuse an existing one.
- **Describe your photos' treatment.** It changes the look the most after the palette.
- **Ask for "preview first"** when you're unsure. You approve stills before the 5–13 minute full render.
- **Name an audience and tone.** That's what decides the wording: formal, casual or slang.
- **More style ideas:** see `vox-styles.md` (archive, map-led, data-led, newspaper, notebook, evidence board, redacted file, timeline ribbon, money trail, paper theatre, poster/propaganda…).
